# Known implementation limitations

Snapshot: 2026-11-03. All entries are open. These limitations concern implemented
behavior; they are separate from [absent capabilities](not-implemented.md) and
[decisions still needed](open-questions.md).

| ID      | Current limitation                                                                      | Effect and reference                                                                                                                                                                                                                                        |
| ------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| LIM-001 | Named throttler windows share a default counter per handler/tracker                     | Multiple checks can increment one counter, so configured counts are not independent quotas. [Throttling](../implementation/throttling.md)                                                                                                                   |
| LIM-002 | Custom throttler uses a fixed 1 ms block duration and hit-count check                   | It ignores resolved block duration and storage blocked state; reset/retry headers report full TTL and windows overwrite header names. [ADR 0006](../ADR/0006-rate-limiting.md)                                                                              |
| LIM-003 | Tracker uses client-controlled User-Agent plus IP; counters are local to one process    | Changing User-Agent changes identity; restarts lose counts and replicas do not share them. Reverse-proxy trust is not explicitly configured. MiddlewareModule retains another throttler configuration. [Throttling](../implementation/throttling.md)        |
| LIM-004 | All caught auth upstream failures become HTTP 401                                       | Clients cannot distinguish credential failures, service outages, timeouts, and registration conflicts by status. [ADR 0005](../ADR/0005-timeouts-errors-retries.md)                                                                                         |
| LIM-005 | General proxy helper rethrows original failures                                         | It has no sanitized upstream exception translation contract if later exposed. [ADR 0005](../ADR/0005-timeouts-errors-retries.md)                                                                                                                            |
| LIM-006 | Response DTOs and HTTP generics do not validate or filter output                        | Actual downstream fields can differ from the documented login contract; omitted password fields in a DTO do not strip data. expiresIn units remain unspecified. [Auth guide](../auth-and-swagger.md)                                                        |
| LIM-007 | Registration validates role as a string and names only as strings                       | Values outside the Swagger role enum and empty names can pass current checks. Allowed role assignment also needs a policy. [Auth guide](../auth-and-swagger.md)                                                                                             |
| LIM-008 | Downstream URLs are captured at import time                                             | ConfigModule .env loading may occur later; exported launch-environment values are available to the reads. [Configuration](../configuration.md)                                                                                                              |
| LIM-009 | Health probes run sequentially and do not validate successful bodies                    | Per-service waits accumulate; top-level ok is not dependency readiness. Health handlers are also throttled. [Operations](../operations.md)                                                                                                                  |
| LIM-010 | HTTP logs include original URLs without redaction                                       | Sensitive path/query data can enter logs. Content-Length is a header value, not measured bytes; finish does not prove receipt and aborted requests lack dedicated close logging. [Logging](../implementation/logging.md)                                    |
| LIM-011 | Inactive JWT helper contracts are not aligned                                           | Strategy expects payload.token and trusts outer identity fields; verification annotation does not validate claims. JWT and session identity shapes differ. [ADR 0003](../ADR/0003-authentication-context.md), [ADR 0004](../ADR/0004-response-contracts.md) |
| LIM-012 | CORS defaults and session-header setup are incomplete for a future browser session flow | Unset origins allow any origin; empty values behave differently. x-session-token is absent from allowedHeaders, and session guards remain inactive. [Configuration](../configuration.md)                                                                    |

Documentation records these constraints without changing runtime behavior. An
under-development status explains incomplete scope but does not turn a known
limitation into an enforced guarantee.
