# Known implementation limitations

Snapshot: 2026-11-18 (proxy retry/timeout and readiness/liveness updates).
Entries remain open except LIM-016; LIM-009 and LIM-013 are partially resolved
as described below. These limitations concern implemented behavior; they are
separate from [absent capabilities](not-implemented.md) and
[decisions still needed](open-questions.md).

| ID      | Current limitation                                                                                           | Effect and reference                                                                                                                                                                                                                                                                                                                                                                          |
| ------- | ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| LIM-001 | Named throttler windows share a default counter per handler/tracker                                          | Multiple checks can increment one counter, so configured counts are not independent quotas. [Throttling](../implementation/throttling.md)                                                                                                                                                                                                                                                     |
| LIM-002 | Custom throttler uses a fixed 1 ms block duration and hit-count check                                        | It ignores resolved block duration and storage blocked state; reset/retry headers report full TTL and windows overwrite header names. [ADR 0006](../ADR/0006-rate-limiting.md)                                                                                                                                                                                                                |
| LIM-003 | Tracker uses client-controlled User-Agent plus IP; counters are local to one process                         | Changing User-Agent changes identity; restarts lose counts and replicas do not share them. Reverse-proxy trust is not explicitly configured. MiddlewareModule retains another throttler configuration. [Throttling](../implementation/throttling.md)                                                                                                                                          |
| LIM-004 | All caught auth upstream failures become HTTP 401                                                            | Clients cannot distinguish credential failures, service outages, timeouts, and registration conflicts by status. [ADR 0005](../ADR/0005-timeouts-errors-retries.md)                                                                                                                                                                                                                           |
| LIM-005 | General proxy fallbacks lack an HTTP error contract                                                          | Plain fallback errors replace original proxy failures, without a defined HTTP status mapping. Updated 2026-11-05; earlier rethrow behavior is retained in ADR 0005. [ADR 0007](../ADR/0007-proxy-resilience.md)                                                                                                                                                                               |
| LIM-006 | Response DTOs and HTTP generics do not validate or filter output                                             | Actual downstream fields can differ from the documented login contract; omitted password fields in a DTO do not strip data. expiresIn units remain unspecified. [Auth guide](../auth-and-swagger.md)                                                                                                                                                                                          |
| LIM-007 | Registration validates role as a string and names only as strings                                            | Values outside the Swagger role enum, explicit null roles, and empty names can pass current checks. Allowed role assignment also needs a policy. [Auth guide](../auth-and-swagger.md)                                                                                                                                                                                                         |
| LIM-008 | Downstream URLs are captured at import time                                                                  | ConfigModule .env loading may occur later; exported launch-environment values are available to the reads. [Configuration](../configuration.md)                                                                                                                                                                                                                                                |
| LIM-009 | Health probes run sequentially and do not validate successful bodies                                         | **Partially resolved, 2026-11-09:** Active HealthCheckService probes now run concurrently. Successful bodies remain unvalidated, normal completion is HTTP 200, and health handlers remain throttled. [ADR 0008](../ADR/0008-health-checks.md), [operations](../operations.md)                                                                                                                |
| LIM-010 | HTTP logs include original URLs without redaction                                                            | Sensitive path/query data can enter logs. Content-Length is a header value, not measured bytes; finish does not prove receipt and aborted requests lack dedicated close logging. [Logging](../implementation/logging.md)                                                                                                                                                                      |
| LIM-011 | Inactive JWT helper contracts are not aligned                                                                | Strategy expects payload.token and trusts outer identity fields; verification annotation does not validate claims. JWT and session identity shapes differ. [ADR 0003](../ADR/0003-authentication-context.md), [ADR 0004](../ADR/0004-response-contracts.md)                                                                                                                                   |
| LIM-012 | CORS defaults and session-header setup are incomplete for a future browser session flow                      | Unset origins allow any origin; empty values behave differently. x-session-token is absent from allowedHeaders, and session guards remain inactive. [Configuration](../configuration.md)                                                                                                                                                                                                      |
| LIM-013 | Proxy return annotation mismatch and fallback response contract                                              | **Partially resolved, 2026-11-05:** [ProxyService](../../src/proxy/service/proxy.service.ts) now uses Promise<unknown>, resolving the former AxiosResponse mismatch. The fixed listing shape and missing fallback provenance remain open. [Proxy resilience](../implementation/proxy-resilience.md)                                                                                           |
| LIM-014 | Proxy cache keys omit identity/headers and have no size bound                                                | Personalized results could be reused across callers if exposed. Expiry is lazy, writes do not invalidate data, and falsy values select defaults. [Proxy resilience](../implementation/proxy-resilience.md)                                                                                                                                                                                    |
| LIM-015 | Circuit semantics do not enforce a deadline or single half-open probe                                        | All methods/paths share service state; client errors count, concurrent state changes can interleave, and replicas do not share state. [ADR 0007](../ADR/0007-proxy-resilience.md)                                                                                                                                                                                                             |
| LIM-016 | TypeScript alias mapping lacks a configured production runtime resolver                                      | **Resolved for the inspected Nest build, 2026-11-09:** Emitted imports are relative and pnpm run start successfully listened during module-fix verification. The earlier claim that an extra resolver was required does not describe that build. start:prod was not separately exercised. [Operations](../operations.md)                                                                      |
| LIM-017 | Health observations have no expiry, readiness returns HTTP 200 on not_ready, and aggregation policies differ | Cached single-service reads may be stale or unknown. `GET /health/ready` calls `HealthService.getHealthStatus()`, which marks any failure as `degraded` (producing `not_ready` with HTTP 200), whereas `GET /health/services` distinguishes `degraded` from `unhealthy`. [Health checks](../implementation/health-checks.md)                                                                  |
| LIM-018 | Internal proxy retries run unconditionally inside the circuit breaker                                        | `ProxyService.proxyRequest` retries all rejections up to 5 total attempts (4 retries) regardless of HTTP method (`POST`/`PUT`/`DELETE`/`PATCH`) or 4xx status, and opening a `proxy-*` circuit (`failureThreshold: 3`) requires up to 15 failed HTTP attempts. [Proxy resilience](../implementation/proxy-resilience.md), [ADR 0009](../ADR/0009-proxy-retries-timeouts-and-health-routes.md) |
| LIM-019 | `TimeoutService` timers are not cleared on early completion and unused retry loop has an off-by-one bound    | `executeWithCustomTimeout` uses `Promise.race` without clearing its `setTimeout` handle or aborting the underlying operation. The unused `executeWithTimeout` helper runs `attempt < config.retries` (`retries` total attempts while logging `retries + 1`) and sleeps after the final failure. [Proxy resilience](../implementation/proxy-resilience.md)                                     |

Documentation records these constraints without changing runtime behavior. An
under-development status explains incomplete scope but does not turn a known
limitation into an enforced guarantee.
