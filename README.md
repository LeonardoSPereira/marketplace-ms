# Marketplace API Microservices

This project is a set of microservices that provide a marketplace API. The services are designed to be modular and scalable, allowing for easy integration and expansion.

This project is under active development and is intended for educational purposes.

Check other active branches for the latest updates and features.

## Services

- **[API Gateway](api-gateway/README.md)**: NestJS entry point for the marketplace microservices, providing request routing, rate limiting, health checks, and downstream proxy resilience.
